🌟 Let's Discover!

Hi, Math Explorer! I'm Scout. Let's discover how numbers help us count!

When we count, we point to each object once and say one number for each object. The last number we say tells how many objects there are.

Scout's example: Point to each picture once and say the counting words in order. The last counting word tells how many objects are in the group. You can count slowly!
